# Task

Describe what you want done. Be specific about three things: the goal, which source material in `context/` to use, and what the deliverable should be (format, length, where it lands in `deliverable/`). The more precise you are, the less the agent has to assume. When something is genuinely unclear, the agent records it in `questions.md` in its output folder rather than guessing.
