# hints

Non-negotiable style and working rules. The agent always follows everything in here. `CLAUDE.md` points to this folder.

## Files

- `working-method.md` — how to work. Don't guess, quote the source, never invent, shorter is better.
- `style.md` — writing-style and anti-slop rules. Adapt to your own domain and language.
- `time.md` — how to reason about evolving or contradictory material.
- `feedback.md` — where you leave review feedback between runs.

Add your own hint files here for project-specific rules. The agent reads everything in `hints/`.
