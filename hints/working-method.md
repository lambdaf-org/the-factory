# Working method

- Don't guess. If something is unclear from the context, write it to `questions.md` in your output folder and move on.
- When describing code, reference the actual source. Quote precisely instead of paraphrasing.
- If the task is to continue or extend an existing document, match its tone and structure exactly.
- Never invent features, facts, or content that isn't in the source material.
- Shorter is better. Don't pad for length.
- Respect the target document's existing format and conventions instead of imposing your own.
